# Changelog

## 0.1.0 - 2026-10-21

Initial release.

- `scan`, `feeds` and `validate` commands.
- Installed-package, `node_modules`, package-cache and lockfile detection for PyPI, npm, crates and Go.
- IOC file hashing, host artifact globs and IOC domain search in shell history and supplied logs.
- Install-time versus live-window classification.
- Rotation checklist scoped to credential stores present on the machine (paths only).
- Text, Markdown and JSON output; configurable exit threshold.
- Bundled feed: litellm 1.107.0 (2026-10-21).
